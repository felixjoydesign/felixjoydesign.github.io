How to format Markdown.

Paste, pick where it is going, copy. There is no button to wait for.

  1. 1

    Paste your Markdown

    From a chat assistant, a README, a note, or anywhere else. The preview and every other version update on each keystroke.

  2. 2

    Press Tidy

    The number on the button is how many lines would change. Tidy rewrites them in one consistent style, and undo puts them back.

  3. 3

    Pick where it is going

    Preview for Google Docs, Word or email. Clean Markdown for GitHub, Notion or a docs site. Plain text for any field that shows symbols literally. WhatsApp for a chat.

  4. 4

    Copy or download

    Copy formatted keeps the headings, bold and lists when you paste into a document. Or download an HTML, Markdown or text file.

What Tidy fixes.

The same document, written one way throughout. Your words, links and order are never touched.

  • Headings that do not render

    #Heading with no space after the pound sign is a paragraph to most Markdown readers. Tidy adds the space. A single #hashtag is left alone.

  • Mixed bullet characters

    A list written with *, + and • together renders as three separate lists. Tidy makes them one list with one marker.

  • Numbered lists stuck on 1

    Steps written as 1. 1. 1. are renumbered 1, 2, 3, so the source reads the way the page does.

  • Tables nobody lined up

    Pipes are aligned into straight columns, respecting each column’s left, right or centre alignment.

  • Two ways of writing one thing

    Underlined headings become # headings, __bold__ becomes **bold**, and every code block gets a proper fence.

  • Spacing and invisible characters

    Runs of blank lines, trailing spaces, Windows line endings, no-break spaces and zero-width characters, all of which break parsing without being visible.

  • Backslashes you did not need

    Tidy only keeps an escape when removing it would change what the text means, so a price like $5 * 2 stays readable.

Markdown formatter questions.

If you have more questions feel free to contact us.

Is this Markdown formatter free?

Yes. It is free with no signup, no limit on length, and no limit on how often you use it.

Is my text uploaded anywhere?

No. Everything runs in this page on your device. Nothing you paste is sent to a server, which is also why the preview keeps up with your typing.

Will Tidy change what my document says?

No. It changes how the document is written, never what it says. Words, links, images, code and the order of everything stay exactly as they were. The only edits are to markers, spacing and alignment.

How do I get rid of the asterisks and pound signs in ChatGPT text?

Paste the text here. To keep the formatting, open Preview and press Copy formatted, then paste into Google Docs, Word or an email. To lose the formatting entirely, open Plain text and copy that.

How do I paste Markdown into Google Docs?

Paste the Markdown here, open Preview, and press Copy formatted. The clipboard then carries real headings, bold, lists and tables, and Google Docs pastes them as formatting rather than as symbols.

Does WhatsApp support Markdown?

Not quite. WhatsApp has its own formatting that looks similar: one asterisk on each side for bold, underscores for italic, tildes for strikethrough. Markdown’s double asterisks show up literally. The WhatsApp view converts one to the other, and turns headings into bold lines.

Which Markdown flavor does it use?

CommonMark, the standard most tools now follow, with the GitHub additions: tables, task lists, strikethrough, autolinks and footnotes. A file that looks right here will look right on GitHub.

What style does Clean Markdown use?

The same one Prettier writes. Headings start with #, bullets with a hyphen, bold uses **, italic uses _, code is fenced, and numbered lists count up. It is the most common style in the wild, so a file tidied here will not be rewritten by the next tool that touches it.

Does the preview show raw HTML?

No. HTML inside the Markdown is kept in Clean Markdown but left out of the preview and the copied formatting, so nothing pasted here can run code in the page.

Will my text still be here if I close the tab?

Yes, on this device and in this browser. The editor keeps a copy in your browser’s own storage so a reload does not lose your work. Clear removes it.

Can I use it for product descriptions?

Yes, and it is a good fit. Write the description once in Markdown, then copy formatted text for your website, plain text for a marketplace listing, and the WhatsApp version for customers who order by chat.
